## Pi execution contract

Use codemode scripts and the unprefixed codemax tools. Read the package execution binding at `../../PI_BINDING.md` when a host-specific operation is unclear. Bundled instructions are read-only. Use `capability` for executable extensions and `learn` for separate evidence-backed skills; never edit this pack. Role/model defaults come from `settings`, only detected model ids, with parent inheritance otherwise. No prose instruction grants external-write, install, credential, billing, or desktop-takeover permission.

# Reflect

Mine this session only. Do not rewrite bundled skills, instructions, principles, playbooks, or references.

1. Read the active branch with `tools.history({action:"current",includeTools:true})` and its evidence with `tools.recall({})`. Use the actual transcript path for fuller context only when needed. Never broaden to unrelated projects.
2. Run independent judgment, tooling, and divergent reviewers with `tools.panel({mode:"reflect",tasks:[...]})`. Pass transcript/artifact paths and the appropriate references under `references/`. Reviewers are read-only, may use available read-only integrations, and may not post updates or edit any skill.
3. Synthesize Accepted, Rejected, and Backlog items. Every finding cites a real entry, artifact, or observed failure. One-off inconvenience and already-covered instructions are not durable learnings.
4. Prefer structural enforcement. A recurring failure belongs in architecture, types, lint, CI, test, or an executable capability/script when that can enforce it. Do not add more prose to compensate for a missing gate.
5. Save a reusable recipe with `tools.learn` only when captured evidence supports it. Use a new descriptive name that extends rather than shadows a bundled skill. Explain trigger, prerequisites, concrete actions, expected proof, recovery, and scope. For an existing codemax-owned learning, use explicit update. Confirm before changing global behavior the user did not request.
6. Summarize the capability/script fixes, new learning paths, rejected findings, and remaining backlog. Do not file external tickets without the user's integration/scope grant.
